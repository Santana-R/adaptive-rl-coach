# Checklist común · entrega LBPWEB

Cada integrante revisa el [paquete](entrega-lbpweb.md) y marca solo lo que comprobó. Si encuentra un problema, lo anota en [#40](https://github.com/Santana-R/adaptive-rl-coach/issues/40) en lugar de marcar la casilla.

## Contenido

- [ ] RF01–RF12 enlazan pantalla, endpoint, datos, tarea y evidencia en la [trazabilidad](../planning/trazabilidad-rf.csv).
- [ ] Las trece pantallas abren desde `public/sitio/html/` y tienen captura de la versión oficial.
- [ ] Los tres CRUD (metas, sesiones, ejercicios) tienen resultado registrado en [resultados CRUD](resultados-crud.md).
- [ ] Diccionario, esquema SQL, migraciones y UML/ERD corresponden a la base vigente.
- [ ] Instalación con Node y Docker reproducida por un integrante distinto del autor (P12).
- [ ] Las observaciones de Fase 2 están atendidas. El profesor no pidió correcciones.
- [ ] Ningún archivo publicado contiene `.env`, claves, tokens, correos reales o contraseñas.

## Formato y envío

- [ ] Fecha de entrega LBPWEB confirmada (tentativa: 23 de noviembre).
- [ ] Formato, nombres de archivo y medio de envío confirmados con la rúbrica.
- [ ] Etiqueta `entrega-lbpweb-v1` creada sobre el commit revisado.
- [ ] Fecha real de entrega y comprobante de recepción registrados (B04, si aplica).
